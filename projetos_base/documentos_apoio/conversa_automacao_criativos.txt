Pelo PDF exibido, o objetivo é receber diretrizes de briefing (estilos, nicho, regras de área de segurança e copy) e cuspir as variações de texto ou prompts visuais para os 3 criativos quadrados (1080x1080) e as versões verticais/Reels (1080x1920).

Existem formas muito mais limpas e escaláveis de resolver isso, divididas pelo nível de esforço técnico:

1. No-Code / Plataformas Multi-Chat (Zero Código)
Se a ideia for apenas disparar vários prompts ao mesmo tempo sem abrir dezenas de abas soltas:
- ChatHub ou BoltAI / TypingMind: Interfaces unificadas onde você digita um único comando e ele dispara a requisição simultaneamente para 2, 4 ou 6 modelos/conversas em paralelo. Você conecta sua chave de API ou usa as contas de chat web direto numa única tela.
- Make.com ou n8n conectado a Google Sheets / Airtable: Você cola as linhas do PDF em uma planilha. O n8n/Make envia cada linha para a API do modelo e devolve os criativos na planilha.

2. Um Único Chat com Saída Estruturada (O Caminho Mais Rápido Sem Instalar Nada)
Você não precisa de 6 chats separados se o modelo puder processar tudo em uma única passada estruturada em JSON ou Markdown. Em vez de abrir 6 abas, use um prompt mestre:
"Aja como um copywriter/designer de performance. Analise o briefing abaixo e gere em uma única resposta o conteúdo completo para os 6 criativos:
- Criativo 1 (Quadrado - Estilo 1 Advertorial)
- Criativo 2 (Quadrado - Estilo 2 Clean com Foto)
- Criativo 3 (Quadrado - Estilo 3 Foto Full-BG)
- Reel 1 (Vertical - Adaptação Estilo 1)
- Reel 2 (Vertical - Adaptação Estilo 2)
- Reel 3 (Vertical - Adaptação Estilo 3)
Respeite as margens de segurança para Reels e a regra de sem promessas não comprováveis. Briefing: [Cole o texto da página]"

3. Script em Python via API (Automação em Lote Total)
Se você precisa rodar blocos de semanas inteiras, um script simples em Python usando a API oficial resolve tudo em 5 segundos direto no terminal:

```python
import os
import json
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

briefing_texto = """
Nicho: Bingo ao vivo em família/online
Áudio: Bateu a saudade de marcar a cartela...
Estilos: Advertorial, Clean com Foto, Foto Full-BG
"""

prompt_sistema = """
Você é um especialista em criativos para Meta Ads. 
Com base no briefing fornecido, gere exatamente 3 criativos 1:1 e 3 roteiros/layouts para Reels (9:16).
Estruture a resposta em seções claras contendo:
- Título/Gancho
- Corpo do texto
- Descrição da cena visual/fotografia
- CTA do botão
"""

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": prompt_sistema},
        {"role": "user", "content": briefing_texto}
    ],
    temperature=0.7
)

print(response.choices[0].message.content)
```

Você pode usar uma biblioteca como `pypdf` para ler todas as páginas e salvar os textos diretamente.
